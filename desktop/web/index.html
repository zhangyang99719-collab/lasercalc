LIMA激光工具箱

微信小程序 v2.1.0 · 浏览器预览（WorkBuddy）

这是把原小程序（limacalc）完整还原成的可交互 HTML 预览：深色仪表盘、底部 5 个 Tab，以及从原 .js 端口过来的真实计算逻辑。

  • 光路设计：拖动滑块实时算聚焦/离焦光斑，光路示意与高斯双曲线为 canvas 动画。
  • 激光参数：功率·速度·光斑·吸收率 + 路径/轨迹 → 能量密度云图（turbo 配色）与工艺模式判定。
  • 脉冲特性：脉冲波形示波器 + 搭接率扫描动画。
  • 日报 / 设置：列表→详情，设置含公众号二维码占位。
  • 能量密度 3D：从①页底部进入，俯视热力图 + 路径叠加。
说明：日报数据为本地示例（原程序走 CloudBase 远程拉取）；图标/二维码为 SVG 占位；其余样式与算法尽量对齐源码。
